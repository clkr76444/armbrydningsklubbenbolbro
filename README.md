**Problemformulering**
Hvordan kan armbrydningsklubben gøres mere attraktiv for unge mellem 16–24 år, som bor i Odense?

**Om dette repository og projektet**
Vi udvikler en ny digital identitet for en armbrydningsklub i Odense med fokus på branding, UX/UI og webudvikling, der skal gøre klubben mere relevant for unge 16–24-årige.

Målet er at gøre klubben mere relevant og attraktiv for unge mellem 16–24 år og samtidig undersøge, hvordan klubbens digitale kommunikation kan udfordre eksisterende forestillinger om armbrydning og hvem sporten er for.

**Målgruppe**
Projektets primære målgruppe er unge som er i mellem 16-24år, og som bor i Odense. Derudover leder målgruppen efter et fællesskab eller en fritidsaktivitet at være en del af.
